# Browser-Isolated-Virtual-Environments-V2
A full-stack platform bundling **noVNC** and **KasmVNC** into a single web portal.  It uses a **Node.js backend** to manage secure user sessions and route traffic, an **HTML/React frontend** to embed desktop streams smoothly inside clean browser `iframes`, and **Docker/Coolify** to host and isolate the remote server environments seamlessly.
